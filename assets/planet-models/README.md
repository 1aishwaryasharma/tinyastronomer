# Scientific planet-model sources

These web-optimized GLB files come from NASA Science's Visualization
Technology Applications and Development (VTAD) 3D resources:

- `mercury.glb` — [Mercury 3D model](https://science.nasa.gov/resource/mercury-3d-model/)
- `venus.glb` — [Venus 3D model](https://science.nasa.gov/resource/venus-3d-model/)
- `mars.glb` — [Mars 3D model](https://science.nasa.gov/3d-resources/mars/)
- `jupiter.glb` — [Jupiter 3D model](https://science.nasa.gov/resource/jupiter-3d-model/)
- `saturn.glb` — [Saturn 3D model](https://science.nasa.gov/resource/saturn-3d-model/)
- `uranus.glb` — [Uranus 3D model](https://science.nasa.gov/resource/uranus-3d-model/)
- `neptune.glb` — [Neptune 3D model](https://science.nasa.gov/resource/neptune-3d-model/)
- `ceres.glb` — [Ceres 3D model](https://science.nasa.gov/resource/ceres-3d-model/)
- `pluto.glb` — [Pluto 3D model](https://science.nasa.gov/resource/pluto-3d-model/)

For browser delivery, the source geometry was quantized without simplifying
its topology, and embedded textures were converted to WebP at no more than
2048 pixels on their longest axis. Shape, UV placement, axial proportions,
surface composites, and Saturn's ring proportions were not redrawn.

No speculative Eris surface map is included. Spacecraft have not resolved its
surface well enough for a truthful global map, so the application renders it
as a deliberately detail-free, mean-color globe.
