# Local fonts

Newsreader and Fragment Mono are bundled under their SIL Open Font Licenses;
see Newsreader-OFL.txt and FragmentMono-OFL.txt in this directory.

Sources, downloaded September 7, 2026:
- https://fonts.gstatic.com/s/newsreader/v26/cY9AfjOCX1hbuyalUrK4397yjIJFJpc.woff2
- https://fonts.gstatic.com/s/fragmentmono/v6/4iCr6K5wfMRRjxp0DA6-2CLnB4NHhqcL71Q.woff2
- https://fonts.gstatic.com/s/fragmentmono/v6/4iC16K5wfMRRjxp0DA6-2CLnB4Z3hK0MzVYBtA.woff2

Newsreader retains its variable weight and optical-size axes. It was subset
with fonttools to Latin letters, combining marks, and punctuation supported
by the original served font. Fragment Mono is Google's Latin subset unchanged.
The fonts now load from the site without a third-party CSS request.
