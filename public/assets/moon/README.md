# Lunar surface maps

Source: NASA’s Scientific Visualization Studio, CGI Moon Kit
https://svs.gsfc.nasa.gov/4720/
Credit: NASA’s Scientific Visualization Studio; Ernie Wright (USRA).

- color-2k.jpg: lroc_color_2k.jpg (2048 × 1024), 2025 LROC color composite, sRGB.
- height-1k.jpg: ldem_3_8bit.jpg (1024 × 512), LOLA elevation, sampled as non-color data for bump shading.

Downloaded unchanged from https://svs.gsfc.nasa.gov/vis/a000000/a004700/a004720/ on 2026-09-04.
The maps are centered on 0° longitude. Both textures use the same UV offset to face the near side toward Earth.
Color is optimized for visualization rather than scientific measurement. Relief shading is illustrative.

Served derivatives (tools/build-texture-variants.py): color-2k.webp and
height-1k.webp (q85) for laptops, color-1k.webp and height-512.webp for phones.
The JPEG sources above stay as the record of the downloaded files.
